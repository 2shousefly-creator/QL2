# Magnetic Storm production artwork

Created 2026-09-16 with the built-in imagegen tool; no CLI/API fallback and no third-party art. Generated PNGs are committed here with original alpha/resolution. Vite supplies hashed URLs. All ship source art faces upward; both renderers rotate it by PI and use centered anchors.

- `stage2-enemy-atlas.png`: 11 distinct entities plus Tempest exposed-reactor variant. Explicit normalized trims in `airCombatStage2Art.ts` accommodate the painted layout. Stage 2 collision capsules are authored against these silhouettes.
- `stage2-vfx-atlas.png`: 5 columns by 6 rows; 10 projectile/helper cells and 20 VFX cells, mapped by named keys in `STAGE2_VFX_ART`. Original transparency retained.
- `magnetic-storm.png`: dark electromagnetic cloud battlefield, separate from Stage 1 terrain. Slow drift, restrained secondary cloud layer, reduced-motion support.
- `main-menu-sky.png`: full-screen sky, cloud sea and mountain ranges. CSS-only presentation motion; no combat state.

The Canvas fallback consumes the same frames as Pixi; no Stage 2 geometric body fallback. Source art production and code inspection only; no runtime visual QA was performed, per task constraints.
